# API Recorder · 全新界面设计方案

> 方向：**浅色主题 + 青绿（Teal）强调色 + 重构信息架构**
> 交付：高保真可交互原型 `api-recorder-redesign.html`（侧边栏切页 + `Ctrl K` 命令面板均可点）
> 目标：既美观、又符合你「录制 → 查看详情 → Mock」的既有使用习惯，同时把"保存/导入的请求库"提升为一等公民。

## 1. 设计令牌（Design Tokens）

### 颜色
| 用途 | 变量 | 值 |
|---|---|---|
| 应用背景 | `--bg` | `#f3f7f6`（带极淡冷调） |
| 面板 / 卡片 | `--surface` | `#ffffff` |
| 次级面 | `--surface-2` | `#f7faf9` |
| 边框 | `--border` | `#e4eae8` |
| 文本主 / 次 / 弱 | `--text / --text-2 / --muted` | `#15201c / #46534d / #7c8883` |
| **强调（青绿）** | `--accent` | `#0d9488` |
| 强调·强（按钮底） | `--accent-strong` | `#0f766e` |
| 强调·柔（选中底） | `--accent-soft` | `#d6f3ee` |
| 成功 / 警告 / 危险 / 信息 | — | `#15a36b / #e08a00 / #e2483b / #2f8be0` |
| HTTP 方法 | GET/POST/PUT/DELETE/PATCH | 绿 / 蓝 / 橙 / 红 / 紫（软底+同色字） |

### 字体 · 圆角 · 阴影 · 间距
- 字体：`Inter` + 中文 `PingFang SC / Microsoft YaHei` 回退；代码 `JetBrains Mono / SF Mono`。
- 圆角：`--r-sm 7px` / `--r 11px` / `--r-lg 16px` / 胶囊 `999px`。
- 阴影：卡片 `--sh-1` 极淡；悬浮 `--sh-2`；弹层 `--sh-pop`。
- 间距：4px 基准栅格（8/12/16/24）。

> 对比度：青绿强调 `#0d9488` 用于链接/选中态；实心主按钮用更深的 `#0f766e` 保证白字 ≥ 4.5:1（WCAG AA）。

## 2. 信息架构（重构后）

```
┌─────────────┬──────────────────────────────────────────────┐
│  侧边导航    │  顶部栏：页面标题 + 全局命令面板(⌘K) + 状态    │
│             │──────────────────────────────────────────────│
│ 🏠 概览      │  主内容区（按导航切换）                       │
│ 📡 录制  (37)│   • 概览：统计卡 + 快捷操作 + 最近活动        │
│ 🧪 Mock (152)│   • 录制：控制条 + 筛选 + 域名请求树 + 详情   │
│ 📚 请求库    │   • Mock：接口列表卡片 + 处理记录             │
│ ⚙ 设置      │   • 请求库：清单 + 端点详情（可编辑 API 文档）
│ 📤 导出      │   • 导出：格式选择 + 范围筛选 + 脱敏 + 预览    │  │
│             │   • 设置：端口 / 脱敏 / 内核 / 外观          │
│ ──          │                                              │
│ ● 录制状态   │                                              │
└─────────────┴──────────────────────────────────────────────┘
```

**与原结构的关键差异**
1. 顶部双 Tab → **左侧常驻导航**，五个入口，录制/Mock 的未读量以徽标呈现。
2. 新增 **「概览」主页**：一屏看清今日录制量、Mock 命中、集合数，并给常用操作入口。
3. 「保存 / 导入」从零散按钮升级为 **「请求库」独立模块**：采用**清单 + 端点详情**两级流——默认页按域名 / IP 归属展示 API 端点清单（不含案例）；点击端点下钻到「端点详情」，左侧目录、右侧正文复用更顺手。
4. 新增 **「导出」独立大功能**：把原先散落在录制页角落的"导出"按钮与设置里的脱敏项，整合为一个独立导航模块——支持 HAR / JSON / Mock 脚本 / OpenAPI 3 多种格式，按"全部 / 按归属 / 按标签 / 手动勾选"筛选范围，脱敏实时预览，导出前可预览产物，统一写入「下载」文件夹（符合项目约定）。
5. 新增 **命令面板（Ctrl K）**：录屏/演示/高频操作中秒切页面、启停录制、导入——符合开发者"键盘优先"习惯。

## 3. 关键界面要点

### 录制页（核心）
- 左栏：内核选择 + 起始 URL + 录制/停止/清空 → 筛选行（搜索/方法/仅API/仅错误）→ **按域名分组的请求树**，方法色标 + 状态码 + 耗时。
- 右栏：请求详情，顶部方法/URL/状态/耗时 + 操作（编辑/复制/注释/导出）；Tab 切「概览/请求头/请求体/响应头/响应体」。
- **JSON 查看器**（招牌能力保留并强化）：行号 + 折叠三角 + 语法高亮（key/str/num/bool/null 分色）+ 字段级 `✎` 注释。

### Mock 页
- 控制台：端口 + Mock 地址 + 启停 + 刷新。
- 左：接口卡片列表（方法色标 + 路径 + ★pin + 命中次数 + 备注/状态），支持过滤/排序。
- 右：处理记录实时流（方法/路径/状态码点/耗时）。

### 请求库页（清单 + 端点详情）
- **两级流**：默认 = **API 清单列表**（需求①：不显示具体案例，只列端点）；点击端点 → **端点详情**（需求②：展示该端点的案例情况 + 可编辑 API 文档）。左侧目录（outline）始终可用，归属（域名 / IP）分组折叠树，展开列出端点，点击任一条目即下钻到端点详情并高亮。
- **左 · 文档目录**：按归属分组的折叠树，每个归属含端点数徽标；顶部过滤框（按归属 / 端点匹配）。当前选中的端点在目录中高亮（`.ol-ep.active`）。
- **默认右 · API 清单**：文档头（标题「请求库 · API 清单」+ 生成时间 + 三项统计：归属分组 / 接口端点 / 捕获案例）；按归属分节（🔗/🌐 图标 + 备注 + 端点数），每节一张端点表（方法色标 / 路径 / 摘要 / 标签 / 案例数 / ›），整行可点击下钻。**此页不含任何案例明细**。
- **端点详情右 · 案例情况**：面包屑「请求库 / 归属 / 端点」可返回清单；标题（方法 + 路径 + 摘要）；**案例表格**（# / 时间 / 状态 / 响应 / 耗时 / 参数），点任意行**就地展开**详情（接口、时间、状态、大小、耗时、参数 + 响应预览），再次点击收起。
- **端点详情右 · API 信息（需求③，可编辑，类似 API 文档）**：
  - 元数据可编辑：`摘要 / 描述 / 负责人` 为 contenteditable 文本，`标签` 可逐个删除或「+ 添加标签」。
  - **字段定义表**：分「请求参数 / 响应字段」两张表，每行 `字段 / 类型 / 必填(切换) / 说明 / 删除`，输入框实时写回数据；底部「+ 添加字段」新增行。增删改即时重渲染，贴合 API 文档编辑体验。
- 数据模型：**归属分组 ⊃ 端点集合（method+path）⊃ 案例（逐次捕获）**，另为每个端点附加 **API 文档信息（info + req/resp 字段定义）**，与录制库天然一致。

### 导出页（独立大功能）
- **定位**：原先的"导出"只是录制页角落一个小按钮、脱敏散落在设置里；现升级为**独立导航模块**，与录制 / Mock / 请求库并列。
- **页头统计**：接口端点数 / 捕获案例数 / 当前导出格式，随范围与格式选择实时变化。
- **① 导出格式（单选卡片）**：HAR（抓包归档，Charles/Fiddler 可打开）、JSON（结构化清单，含字段定义与案例摘要）、Mock 脚本（基于录制库生成 Flask Mock 服务源码）、OpenAPI 3（生成 openapi.yaml，可导入 Swagger/Apifox）。选中卡片高亮（青绿描边 + 柔底）。
- **② 导出范围（分段切换）**：
  - 全部录制：导出整个录制库；
  - 按归属：下拉选域名 / IP；
  - 按标签：下拉选标签（标签源自端点 API 文档里的 tags）；
  - 手动勾选：端点勾选列表（方法色标 + 路径 + 归属 + 案例数）。
  - 切换时页头统计与底部预估同步更新。
- **③ 脱敏**：开关 + 替换映射（中文→ / 数字→ / 英文→），下方**实时预览**示例文本脱敏前后对照；默认开启（与设置中的脱敏概念同源，真实实现建议共享同一份配置）。
- **④ 预览 + 导出**：底部固定操作条显示"预计导出 N 接口 / M 案例 · 格式 · 已脱敏"，「预览」弹出 modal 展示将要生成的产物摘要（JSON 示意 / OpenAPI paths / Mock 路由），「导出到下载文件夹」触发后 toast 提示落盘路径（统一写入系统「下载」文件夹，符合项目约定）。

### 设置页
- 分区：通用（端口）、脱敏（开关 + 中文/数字/英文 映射）、浏览器内核（自带/本机 开关）、外观（浅/深主题预览）。

## 4. 可用性（符合用户习惯）要点
- **键盘优先**：`Ctrl K` 命令面板；录制状态脉冲指示，长时录制不疲劳。
- **信息密度友好**：开发者工具需一屏多看，用卡片 + 紧凑列表而非大留白。
- **状态可见**：底部/侧栏录制状态、Mock 运行态、各请求状态码色点，随时可读。
- **一致组件**：按钮/输入/标签/方法徽标全站统一，降低认知成本。
- **可访问性**：青绿主按钮达 AA 对比度；焦点环、语义结构、44px 命中区预留。

| 请求库三栏 | 新增 | 复用现有"保存/导入"数据；左=归属(域名/IP)分组、中=同 method+path 端点集合、右=该端点逐次捕获案例；新增 `#panelLibrary` |
