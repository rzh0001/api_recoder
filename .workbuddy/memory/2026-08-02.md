## Mock 端口可配置（方案 B 落地）
- 用户要求：Mock 端口要可配置，否则别人没法对接测试。
- **app/config.py**：新增 `MOCK_PORT`（优先级：环境变量 `API_RECORDER_MOCK_PORT` > `config.json` 的 `mock_port` > None 随机）。
- **app/server.py**：
  - `api_get_config` 返回 `mock_port`；`api_set_config` 增加 `mock_port` 校验(1-65535)与持久化。
  - `api_mock_start`：前端未传 `port` 时回退到 `MOCK_PORT`（再不行由 MockManager 随机分配 `0`）。
- **static/index.html**：设置面板加「Mock 端口」输入框(`#mockPortInput`)；Mock 页 subbar 加端口输入框(`#mockPortInput2`，预填配置值)。
- **static/app.js**：`savePortCfg` 同时提交 `port`+`mock_port` 并回填 subbar；加载时两框从 `/api/config` 的 `mock_port` 预填；启动 Mock 时把 subbar 端口下发（`{port: mport}`，空=用配置）。
- **static/styles.css**：新增 `.mock-port` / `.input-sm`（紧凑端口框）。
- **顺手修了一个真前端 bug（重要）**：`applyLocks()` 里 `startMockBtn.disabled = recordingActive || (mockRunning ? true : startMockBtn.disabled)` —— `mockRunning=false` 时三元回退到 `startMockBtn.disabled` 的**旧值**，导致运行中被禁用后、停 Mock 永远不恢复。改为显式 `startMockBtn.disabled = recordingActive || mockRunning`。验证已确认停 Mock 后 start 恢复启用。
- **验证**：Playwright+Edge 桩（扁平响应结构，贴合真实后端）全过 —— 设置面板/ Mock 页端口框预填 8902；默认启动回退配置 8902、状态栏显示「Mock 运行中 :8902」；自定义 7777 生效；停 Mock 后 start 恢复；配置保存 `mock_port=9999` 且下次回退用到（持久化生效）；无 JS 报错。
